Octerse makes GitHub Copilot answer like an engineer on their 36th on-call hour — code first, words last. Same accuracy, ~65% fewer output tokens. Here's the full setup, end to end.

0Prerequisites

  • A git repository — octerse installs per-repo, nothing global
  • GitHub Copilot in VS Code and/or Copilot CLI
  • Optional: gh CLI for the gh octerse extension, jq for spend reports, Node 18+ for the MCP proxy

1Install

From the root of any repo:

# macOS / Linux / WSL / Git Bash
curl -fsSL https://raw.githubusercontent.com/heisenberg-alt/octerse/main/install.sh | bash

# Windows (PowerShell)
irm https://raw.githubusercontent.com/heisenberg-alt/octerse/main/install.ps1 | iex

# or via the gh CLI
gh extension install heisenberg-alt/octerse
gh octerse install --mode full

This writes exactly five things — nothing else is touched:

PathWhat it is
.github/copilot-instructions.mdThe active terse-mode payload (≤80 lines)
.vscode/settings.jsonCopilot instruction + prompt-file keys, merged not overwritten
.octerse/skills//octerse-* prompt files for Copilot Chat
AGENTS.mdOptional, with --with-agents
.octerse/Local state (mode, stats)
Useful flags: --dry-run previews every write, --force overwrites, --uninstall removes everything, --with-context adds context-discipline rules (step 3), --with-shrink adds the MCP proxy example.

Reload the VS Code window, then try /octerse-help in Copilot Chat.

3Engineer your context

Output is half the bill. The other half is everything re-sent on every turn — instructions files, history, tool output. Audit it:

gh octerse context
  Sent every turn:
    .github/copilot-instructions.md   52 lines   1,840 B   ~460 tok
    AGENTS.md                        316 lines  15,195 B  ~3,798 tok
    ── per-turn tax                  368 lines  17,035 B  ~4,258 tok

Then act on the findings:

bash install.sh --with-context       # ≤40-line context-discipline rules
gh octerse audit                     # flag bloat patterns
gh octerse compress AGENTS.md        # shrink in place — reversible
gh octerse compress --restore AGENTS.md   # undo
Compress refuses politely when there's nothing to gain: untracked files, symlinks, files where the marker would outweigh the savings. Every rewrite leaves a .original.md backup. Read the full context engineering guide.

4Shrink MCP descriptions (optional)

MCP servers ship verbose tool descriptions that you re-pay for every turn. Wrap any stdio server with the octerse-shrink proxy — typical saving is 60–80% of description bytes; tools/call payloads pass through byte-for-byte:

// .vscode/mcp.json
"filesystem": {
  "type": "stdio",
  "command": "npx",
  "args": ["-y", "octerse-shrink", "--",
           "npx", "-y", "@modelcontextprotocol/server-filesystem", "${workspaceFolder}"]
}

5Watch the spend

gh auth refresh -s manage_billing:copilot,read:org   # once
gh octerse spend --org acme              # $ this billing period
gh octerse spend --org acme --since 7d   # last 7 days
gh octerse spend --org acme --json       # pipe to jq / dashboards
gh octerse spend --org acme --calculator # open the UBB Estimator pre-filled

Reads only api.github.com with your existing gh token. No telemetry, nothing written to disk.

6Build the habits

  1. New session per task — /clear between unrelated work
  2. Open with /plan for anything beyond a one-liner
  3. Reference @path/file:line, never directories
  4. /compact before you switch focus, not after the window is full
  5. Default to mid-tier models; /model up only when stuck
  6. Keep instructions ≤80 lines — gh octerse audit
  7. End every session with /usage
  8. Delegate long work with /delegate

gh octerse tips prints this checklist in your terminal.
